# HealthStat Hospital Efficiency Analysis

## Overview

In healthcare, improving efficiency while maintaining high-quality patient care is a top priority. This Power BI case study explores a real-world dataset to uncover hospital efficiency insights for a fictional consulting company called HealthStat. The project aims to analyze attributes impacting patient length of stay (LOS) and costs, identifying factors contributing to differences among hospitals. The insights generated will help the HealthStat team make informed decisions to enhance hospital performance.

## Objectives

- Analyze patient length of stay (LOS) and cost per patient discharge.
- Identify factors contributing to hospital performance differences.
- Create insightful visualizations and calculated measures using DAX.
- Develop a comprehensive business dashboard to communicate findings.

## Project Steps

### 1. Data Import and Model Connection

- Import the dataset into Power BI.
- Connect and structure the data model.

### 2. Exploratory Data Analysis

- Conduct initial exploratory analytics to understand the dataset.
- Measure efficiency in healthcare using key metrics.

### 3. DAX Measures and Calculations

- Create calculated measures and columns using DAX.
- Identify hospital performance outliers.
- Reveal attributes most influencing length of stay and cost per patient discharge.

### 4. Dashboard Development

- Build a cohesive and interactive report.
- Incorporate HealthStat branding for visual appeal.
- Optimize navigation features for user-friendliness.
- Add dynamic titles and other interactive elements.

## Tools and Technologies

- **Power BI**: Data visualization and business intelligence tool.
- **DAX**: Data Analysis Expressions for creating measures and calculations.
